Códigos

GameShark, Action Replay ou CodeBreaker (o tipo é descoberto sozinho). Cole cada código numa caixa (pode ter várias linhas) e aperte Aplicar. Fica salvo neste aparelho, só para este jogo.

O código tem que ser da mesma versão da ROM (USA, Europa, Japão). Se o jogo travar ou ficar estranho, desligue o código e aplique. O que o jogo gravar no save com o código ligado continua lá depois.
